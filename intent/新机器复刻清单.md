# 新机器复刻清单 —— 从零到能用手机遥控

> **一句话**：clone 三个仓库 → 跑一条安装脚本 → 手工填三处占位符 → 重启 DSH。
>
> 详细原理见 `intent/dsh.md`；本文件只回答「换台电脑，按什么顺序敲什么」。

## 0. 前置

- Windows + PowerShell（**必须是 PowerShell 5.1/7 的 pwsh.exe 正常版**，不要用 ISE 内置宿主）
- 已装 DSH Desktop
- 三个仓库放在**同一目录**下（脚本靠相邻关系发现源码）：

```
<你的工作区>/
├─ dsh-personal-setup/    ← 本仓库
├─ dsh-native-mobile/     ← git clone https://github.com/caixuf/dsh-native-mobile.git
└─ dsh-rea/               ← git clone https://github.com/caixuf/dsh-rea.git
```

> 也可以放在 `~/Downloads/aiwork/` 下，脚本同样能发现。

## 1. 装 DSH 环境（一条命令）

```powershell
cd dsh-personal-setup
Set-ExecutionPolicy -Scope Process Bypass -Force
.\scripts\install-dsh.ps1 -DryRun     # 先看它要干什么（纯只读，不写任何文件）
.\scripts\install-dsh.ps1             # 真装
```

脚本会做三件事：
1. 装 16 个公共 npm bundle（含 `dsh-bot-gateway`、`dsh-mnemon`、`dsh-sync`…）；
2. **从本地源码**装 2 个自研宿主插件（`dsh-mobile-gateway`、`dsh-rea`）——
   它们没发 npm，走 `dsh plugin add` 会 404；
3. 写 `<dsh-home>/cordis.patch.yml`（机器级补丁）+ 复制机器级 node_modules。

## 2. 重启 DSH

**必须重启**：Node ESM 不热重载，patch 改动也要重启才读盘。
（DSH 运行中改 `cordis.patch.yml` 会让设置写入的 revision 乐观锁错位。）

## 3. 打通公网（这一步换机最容易漏）

DSH 默认只监听本机，手机在外面连不上。需要 FRP 隧道：

1. 拿 `frpc.exe`（腾讯云 frp 官方，或从旧机器拷）放到一个目录，比如 `~/Downloads/android-toolchain/`；
2. 把模板 `templates/dsh/frpc.toml` 复制成 `frpc.toml`，与 `frpc.exe` 同目录；
3. **填三处占位符**：
   - `serverAddr` = VPS 公网 IP
   - `auth.token` = 与 VPS 上 frps 一致的 token（**不要提交进 git**）
   - `remotePort` = 与 VPS 上 frps 一致（默认 2443，且 frps 侧**只绑回环**）
4. 运行 `.\frpc.exe -c .\frpc.toml`，日志出现 `start proxy success` 即通；
5. VPS 侧 Caddy 做路径白名单 + TLS 终止（配置在 `dsh-native-mobile/docs/public-access.md`）。

**自检**：

```powershell
curl.exe -sk --noproxy '*' https://<VPS_IP>:2444/mobile-gateway/health
# 期望：{"ok":true,"service":"dsh-mobile-gateway",...}
```

> ⚠️ `--noproxy '*'` 必须加：本机全局代理会让「连不通」看起来「连得通」，
> 也让真实失败路径被掩盖（见 `intent/wsl.md` 同类坑）。

## 4. 编译手机端（可选，只在自己改 App 时需要）

```powershell
$env:JAVA_HOME = "<你的 JDK17 路径>"     # 必须 17
cd ..\dsh-native-mobile\apps\android
.\gradlew.bat assembleDebug
# 产物：app\build\outputs\apk\debug\app-debug.apk
```

装到已连 USB 的手机：

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## 5. 手机端登录

| 项 | 值 |
|---|---|
| 电脑地址 | `https://<VPS_IP>:2444` |
| 账号 | 见 DSH 的「移动网关」管理面板 |
| 密码 | 同上（面板可一键重置） |

## 6. 最终验收（别跳过这三条）

```powershell
cd ..\dsh-personal-setup\..\dsh-native-mobile

# ① 网关 e2e（应为 81/0）
node packages\dsh-mobile-gateway\test\e2e.mjs

# ② 事件流端到端（应为 9/0）
node packages\dsh-mobile-gateway\scripts\verify-mux-events.mjs http://127.0.0.1:19387 <user> <pass>

# ③ 公网全接口巡检（应为 45/0；本机跑则为 46/0）
node packages\dsh-mobile-gateway\scripts\check-all-endpoints.mjs https://<VPS_IP>:2444
```

全绿 = 和这台机器一样丝滑。

## 已知会踩的坑（都实测过）

| 坑 | 症状 | 处置 |
|---|---|---|
| `.ps1` 存成无 BOM 的 UTF-8 | 中文吞引号 → `ParseError: 缺少右花括号` | 存成**带 BOM** 的 UTF-8；本仓库脚本已是 |
| `.cmd` 里写中文注释 | 报 `xxx 不是内部或外部命令` | `.cmd` 一律**纯 ASCII** |
| 巡检脚本默认重置密码 | 紧接着的脚本报 `mismatch`，看着像功能坏了 | 现在默认只读，要改加 `--reset-credentials` |
| 脱敏把判定逻辑一起换掉 | `publicMode` 对真实公网恒 false | 判定要依赖**结构特征**，别依赖具体 IP |
| DSH 运行中改 patch | 设置保存全部被拒（revision 乐观锁） | 改完**重启 DSH** |
